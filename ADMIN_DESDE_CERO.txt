BARBERÍA LOS MÁGICOS — ADMINISTRADOR CON CORREO REAL

Esta versión cambia únicamente el inicio de sesión del ADMINISTRADOR:

ANTES:
Usuario "admin" -> admin@losmagicos.app

AHORA:
El administrador entra directamente con su correo real de Firebase Authentication
y la contraseña que tú establezcas.

Los BARBEROS continúan usando:
usuario + PIN de 6 dígitos

PASOS EN FIREBASE
1. Authentication > Usuarios
2. Elimina el usuario antiguo admin@losmagicos.app si ya no lo vas a usar.
3. Agrega un usuario con TU CORREO REAL.
4. Define una contraseña nueva que recuerdes.
5. Copia el UID de ese usuario.

FIRESTORE
6. Firestore > Datos > users
7. Elimina el documento del administrador antiguo si corresponde.
8. Crea un documento NUEVO cuyo ID sea EXACTAMENTE el UID del usuario de tu correo real.
9. Agrega:
   active     boolean  true
   emailAlias string   TU_CORREO_REAL
   name       string   Administrador
   role       string   admin
   username   string   admin

LOGIN EN LA WEB
Correo: tu correo real
Contraseña: la que acabas de crear en Firebase Authentication
